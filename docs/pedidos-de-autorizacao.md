**Para:** contato@cbf.com.br
**Assunto:** Pedido de autorização para uso de dados das súmulas (Brasileirão Feminino A1 e Série A)

Prezados,

Meu nome é [seu nome] e mantenho, como projeto pessoal e sem fins comerciais, uma base de dados sobre a história do Sport Club Corinthians Paulista, com o mesmo peso para o time masculino e para o feminino. A base reúne só fatos das partidas (data, adversário, placar, autores e minutos dos gols, técnico) e cita a fonte de cada informação.

Os termos de uso do site da CBF não permitem reproduzir dados sem autorização específica, por isso escrevo para pedi-la. Gostaria de usar as informações das súmulas destas competições, apenas nas partidas do Corinthians:

O uso seria restrito aos fatos acima, sem reproduzir os documentos, sempre com crédito à CBF e com link para a súmula de origem. Hoje a base é de uso privado; se um dia for aberta ao público, isso só aconteceria dentro das condições que vocês definirem.

Se for possível, gostaria também de saber se a CBF tem algum canal oficial para fornecer esses dados a projetos de pesquisa ou de memória do futebol.

Fico à disposição para qualquer esclarecimento.

## Corinthians, Comunicação

**Para:** comunicacao@sccorinthians.com.br
**Assunto:** Pedido de autorização: uso de dados de jogos das Brabas publicados no site oficial

Prezados,

Meu nome é [seu nome], sou torcedor do Corinthians e mantenho, como projeto pessoal e sem fins comerciais, uma base de dados sobre a história do clube, com o mesmo peso para o masculino e para as Brabas. A base reúne só fatos das partidas (data, adversário, placar, autores dos gols, técnico) e cita a fonte de cada informação.

Os dados das Brabas são o ponto mais difícil: de 2016 a 2021 não existe fonte aberta completa, e o arquivo de notícias do site oficial é a fonte mais confiável que encontrei. Como o site informa que todos os direitos são reservados, escrevo para pedir autorização para usar os fatos das partidas publicados nas notícias do clube desde 2016, sem reproduzir textos, fotos ou marcas, sempre com crédito ao Corinthians e link para a notícia de origem.

Também gostaria de saber se o clube tem uma relação organizada dos jogos do futebol feminino (datas, placares, técnicos de cada temporada) que possa ser compartilhada, o que evitaria qualquer coleta no site.

Hoje a base é de uso privado; se um dia for aberta ao público, isso só aconteceria dentro das condições que vocês definirem. Se ajudar, posso compartilhar com o clube os dados já reunidos.
